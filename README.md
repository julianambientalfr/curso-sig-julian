# curso-sig-julian

Trabajos del curso Servicios SIG y Sitios Web de la Maestría en Sistemas de Información Geográfica.

## Cómo se ejecuta

Los ejercicios se realizan mediante PowerShell, Git, Python y herramientas SIG.

## De dónde salen los datos

Los datos geográficos de Boyacá se descargan mediante los scripts del curso y se utilizan para prácticas de análisis y procesamiento SIG.
